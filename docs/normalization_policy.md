# 정규화 정책

`scripts/normalize_terms.py`는 아래 규칙을 **고정** 적용합니다.

1. 유니코드 정규화: `NFKC`
2. 양끝 공백 제거: `strip()`
3. 연속 공백 정리: 모든 연속 공백(`\s+`)을 한 칸으로 통일
4. 괄호/특수문자 처리
   - 괄호 `()[]{}`: **유지**
   - 하이픈(`-`), 슬래시(`/`), 퍼센트(`%`) 등 의미 구분에 자주 쓰이는 특수문자: **유지**
   - 문장부호 삭제는 수행하지 않음

정규화 목적은 비교 일관성 확보이며, 원문 보존은 `term` 필드로 유지합니다.
